Algorithm to store lower triangular matrix:
1. Initialize a 1D array U of size n*(n+1)/2 and an index variable i = 0.
2. Loop j from 0 to n-1:
3.     Loop k from 0 to j:
4.         Set U[i] = A[j][k]
5.         Increment i by 1
6.     End Loop
7. End Loop

Algorithm to retrieve lower triangular matrix:
1. Initialize a 2D array A of size n x n.
2. Loop j from 0 to n-1:
3.     Loop k from 0 to n-1:
4.         If k > j:
5.             Set A[j][k] = 0
6.         Else:
7.             Set A[j][k] = U[(j * (j + 1)) / 2 + k]
8.         End If
9.     End Loop
10. End Loop
