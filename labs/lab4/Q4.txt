Algorithm to retrieve tridiagonal sparse matrix B from 1D array U:
1. Initialize a 2D array B of size n x n with all zeros.
2. Loop j from 0 to n-1:
3.     Loop k from 0 to n-1:
4.         If absolute value of (j - k) <= 1:
5.             Set B[j][k] = U[2 * j + k]
6.         Else:
7.             Set B[j][k] = 0
8.         End If
9.     End Loop
10. End Loop
