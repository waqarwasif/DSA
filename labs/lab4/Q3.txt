Algorithm to store tridiagonal sparse matrix B into 1D array U:
1. Initialize index variable i = 0.
2. Loop j from 0 to n-1:
3.     Loop k from 0 to n-1:
4.         If absolute value of (j - k) <= 1:
5.             Set U[i] = B[j][k]
6.             Increment i by 1
7.         End If
8.     End Loop
9. End Loop
