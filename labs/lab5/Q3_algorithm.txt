Algorithm for Question 3:

Part 1: Input and Validation
1. Ask the user for the number of elements.
2. Repeat the following until the user provides a sorted array:
   a. Ask the user to input the elements.
   b. Check if the elements are in ascending order.
   c. If they are sorted, proceed. Otherwise, display an error and prompt again.

Part 2: Modified Binary Search with Insertion
Algorithm: modifiedBinarySearch(data, item)
1. Initialize beg to 0 and end to the last index of the data array.
2. Repeat while beg is less than or equal to end:
   a. Calculate mid as (beg + end) / 2.
   b. If data[mid] equals item:
      i. Output that the item was found at index mid.
      ii. Return from the function.
   c. If item is less than data[mid]:
      i. Set end to mid - 1.
   d. Else:
      i. Set beg to mid + 1.
3. If the loop finishes, the item was not found.
4. Insert the item into the data array at the index indicated by 'beg'. This position maintains the sorted order of the array.
